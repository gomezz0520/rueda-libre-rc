# Rueda Libre RC

Página de venta de carros a control remoto (Medellín, Colombia). Los pedidos llegan por WhatsApp.

- `index.html`: toda la página. Los **precios, asesores y textos de cada modelo** se editan en el bloque `CONFIG` y `MODELOS` al final del archivo.
- `img/`: fotos y fichas técnicas.
- `video/`: videos de los carros (comprimidos para web).

Se publica sola en Vercel cada vez que se sube un cambio a la rama `main`.

Ver [PENDIENTES.md](PENDIENTES.md).
